# FocusFlow

A modern landing page for an academic productivity app designed to help students stay focused, build productive habits, and improve their study routines.

## Overview

FocusFlow is a study-focused productivity platform that combines distraction-free workspaces, smart timers, progress insights, and accountability features to help learners stay in their zone and achieve better results.

This project is a single-page marketing website built with HTML and CSS, featuring a sleek hero section, feature highlights, customer testimonials, and a responsive footer.

## Features

- Clean, conversion-focused hero section
- Study productivity branding and messaging
- Feature cards for key product capabilities
- Responsive layout for desktop and mobile screens
- Dark mode toggle for enhanced usability
- Testimonial section with social proof
- Footer with branding, links, and legal information

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (for the mobile menu and dark mode toggle)

## Getting Started

Because this is a static front-end project, you can run it in any of the following ways:

1. Open `index.html` directly in your browser, or
2. Serve the project locally with a simple web server.

### Option 1: Open directly

Double-click `index.html` in your file explorer, or open it in a browser.

### Option 2: Run a local server

From the project directory, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

You can easily modify the landing page copy, colors, or layout by editing:

- `index.html` for content and structure
- `styles.css` for styling and responsiveness
- `image.png` for the hero background image
